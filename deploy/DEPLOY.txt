Hostinger deployment — Kukuweb / Never Quit Punjabi
==================================================

1) UPLOAD
   - Upload everything inside the "dist" folder into your domain's public_html
     (or into a subfolder if you use one).
   - Preserve the folder structure (admin/, assets/, config/, includes/, uploads/, etc.).

2) DATABASE (hPanel → Databases → MySQL)
   - Create a MySQL database and user; note host (often something like mysql.hostinger.com or localhost).
   - Open phpMyAdmin → Import → upload sql/schema.sql (or run the SQL from that file).

3) CONFIGURE config/database.php
   - Set $DB_HOST, $DB_USER, $DB_PASS, $DB_NAME to your Hostinger MySQL credentials.

4) SITE URL — config/app.php
   - Change SITE_URL to your live URL, e.g. https://yourdomain.com
   - Or set server env KUKUWEB_SITE_URL (if your plan supports it) and keep app.php as-is.

5) FIRST RUN
   - In a browser open: https://yourdomain.com/setup.php once (creates tables if needed).
   - Delete setup.php from the server after a successful setup.

6) UPLOADS
   - Ensure uploads/posts/ exists and is writable (755 or 775) so featured images work.

7) GOOGLE OAUTH (optional)
   - In Google Cloud Console add Authorized redirect URI:
     https://yourdomain.com/auth/google-callback.php

8) EMAIL (password reset)
   - Hostinger mail or SMTP: adjust includes/mail.php if you use SMTP instead of PHP mail().

ZIP for upload: zip the contents of dist/ (not the dist folder name itself) if your file manager prefers a single archive.
